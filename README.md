21届智能视觉比赛业已结束，目前已经有了一些开源方案，他们的思路和代码构建都十分优秀，笔者自愧不如，但是也愿意分享一下拙见，以供各位车友交流参考用

本方案的特点如下  
1.车载屏幕使用了四个Apriltag辅助定位  
2.使用摄像头均为openartplus，代码在openartmini上可能不适用  
3.分类模型使用了ELQ训练，目标检测模型则是用了逐飞提供的训练方案  
4.实现了较为鲁棒的视野机制，能一次检测多目标（包括人物+数字），目前实现的较为鲁棒的视野为4格，是以车前方为底顶点的一个倒三角形，但是由于最终定位精度等问题，赛场没有使用此版本  
5.定位帧率约为40FPS，也提供了鲁棒稍差的60FPS版本，但是考虑到车载屏幕本身刷新率是60Hz，也已经够用
