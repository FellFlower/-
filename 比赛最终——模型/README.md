在此给出部分文件说明以及思路讲解：

main.py为实际比赛使用版本，只有单格视野

main\_debug.py为测试多目标的版本

main\_new.py为多目标检测版本

这里解释一下多目标检测是如何做到的，实际上是一种伪多目标，在训练出yolo检测模型的情况下，由于本届规则下的特殊性，可以配合上位机让车到合适的位置来使得目标出现在镜头的某一特定区域，然后手动划分roi，之后上位机解析每个roi需要何种模型进行分类，以串口发送给摄像头，摄像头以yolo检测模型来识别到目标位置，但是由于裁取的roi分辨率等问题yolo会不准，于是我在一次yolo框出的画面上再此调用一次yolo，实现了不错的效果。这样在手动划分roi的时候可以稍微多划一点，代价是识别时间会多一点。不过这个方案是在单目标基础上整出来的，我们进行过多目标检测yolo模型的训练测试，效果不佳，于是用这个方法进行平替。最终比赛处于稳妥目的还是没有采用。

main2.py是一个在上述基础上视野更大的版本，因为同样原因最终放弃

test.py是main2的测试版本



目前实现的多目标版本是一个视野机制，能看到一定视野范围内的所有目标，当然也引入了视野遮挡机制，如果被遮挡上位机不会发出识别命令，具体代码在上位机主控中。当视野中有待检测目标，会根据小地图解析他们在画面中应当存在的roi以及分类的类型，然后发送给摄像头指令。
